## Traceability rule

Consequential findings should identify the source IDs they depend on. AI outputs may point to sources, but they do not replace them. Review should remain visible between AI output and reviewed finding.

The chain is: **source → AI output (if used) → review → finding → decision**.

Update it when an artifact is added, changes state, is superseded or withdrawn, gets reviewed, or its permitted use changes in a way that affects how another researcher should handle it.
