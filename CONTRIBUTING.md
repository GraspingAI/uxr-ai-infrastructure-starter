# Contributing

Thanks for helping improve this public learning resource.

This repository is intentionally small. Contributions should make the research infrastructure easier to understand, inspect, reuse, or maintain without turning the starter into a large framework or generic prompt library.

## Before proposing a change

Ask:

1. What problem does this change solve?
2. Who would benefit from it?
3. Does it preserve or improve **Find / Trust / Reuse / Maintain**?
4. Does it introduce unnecessary complexity?
5. Is every example safe to publish publicly?

## Public-data rule

Do not contribute participant data, employer- or client-confidential material, proprietary research artifacts, credentials, private URLs, or other protected information.

Use fictional, synthetic, or clearly reusable public material only.

## Suggested workflow

For a meaningful change:

1. Create a branch from `main`.
2. Make the smallest coherent change.
3. Commit it with a message that explains what changed.
4. Open a pull request explaining **why** the change should become part of the shared version.
5. Review the diff before merging.

This workflow is intentionally visible because the repository is also a teaching example of lightweight versioned practice.
