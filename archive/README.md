# Archive

This directory holds material that should remain findable for history but should no longer be treated as current.

Archiving is different from deleting. Keep something here when its history still matters, but mark clearly **what superseded it and when**.

## Minimum archive note

For an archived artifact, record:

- **Status:** Superseded / retired
- **Superseded by:** link or path to the current artifact
- **Date:** when the status changed
- **Reason:** why it is no longer current

Do not use the archive as a dumping ground for material nobody wants to classify. If an artifact has no continuing value, deletion may be the clearer choice when policy allows it.
